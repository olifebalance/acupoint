# MIMO 사이트 — 편집실 시안 (코드결 2차)

1차 시안(`../mimo/`)과 이음의 현재 사이트와는 뼈대부터 다르게 지은 시안이다.
빌드 과정과 외부 라이브러리가 없다. 이 폴더를 그대로 웹 서버에 올리면 된다.

```sh
cd mimo-cut && python3 -m http.server 8766   # http://localhost:8766
```

## 생각

- 사이트 전체가 영상 편집 화면이다. 화면 아래에 타임라인이 고정되어 있고, 스크롤하면 재생 막대가 움직인다.
- 타임라인을 손가락·마우스로 밀면 화면이 같이 움직인다. 구간을 누르면 그 자리로 간다.
- 재생 막대가 작품 구간에 들어서면 화면 전체 색과 글자색이 그 작품 색으로 통째로 바뀐다.
- 타임코드의 전체 길이 02:26은 작품 다섯 편 길이의 합(146초)이다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 글과 구조. 영문판은 이 글과 `app.js`의 `WORKS` 목록만 바꾸면 된다 |
| `style.css` | 색·글자·배치·움직임 |
| `app.js` | 타임라인, 색 바꾸기, 영상 재생, 문의 내용 만들기 |
| `assets/` | 작품 영상 5편과 포스터, 미모 캐릭터 영상 4개. 현재 사이트에서 그대로 가져옴(재인코딩 없음) |
| `fonts/` | Pretendard(한글 2,350자 + 라틴), Unbounded(로고), JetBrains Mono(타임코드). 모두 SIL OFL |

## 지킨 것

- 영상은 한 번에 하나만 재생한다. 소리는 버튼을 눌렀을 때만 나고, 다른 구간으로 가면 꺼진다.
- 한 화면에 움직이는 것은 하나. 지나가는 글자 띠는 없다.
- `prefers-reduced-motion`이면 움직임을 끈다.
- 문의 양식은 내용을 정리·복사만 하고 전송하지 않는다.
- 가격 금액, 후기, 실적 표현은 넣지 않았다.
