# MIMO의 거리 — 펜 선화 상점가 (예시)

펜으로 그린 작은 상점가. **작품 하나가 가게 하나**다.

- 해(밤에는 달)를 끌면 시간이 바뀌고, 저녁이 되면 창문에 불이 하나씩 켜진다.
- 가게를 누르면 그 작품 영상이 소리와 함께 재생된다. 키보드로는 Tab으로 가게를 고르고 Enter.
- 지나가는 사람을 누르면 멈춰서 손을 흔들고, 고양이는 기지개를 켜고, 전깃줄의 참새는 날아갔다 돌아온다.
- 마우스·손가락을 움직이면 바람이 되어 차양·간판·등불이 흔들린다.
- 동작 줄이기 설정이면 아무것도 저절로 움직이지 않는다. 해를 끌면 그 시간의 그림으로 바뀐다.

## 작품이 바뀌거나 늘어날 때

`src/works.ts`의 목록 한 줄이 가게 하나다. 줄을 더하면 거리가 그만큼 길어진다.
PC에서는 카드 폭에 맞춰 줄어들고, 높이가 300px 아래로 내려가야 할 만큼 많아지면 옆으로 민다.
폰에서는 처음부터 옆으로 민다.

- 영상과 포스터는 `public/assets/<id>.mp4`, `public/assets/<id>.webp`에 넣는다.
- `kind`로 가게 모양을 고른다: `food` `fashion` `bakery` `books` `story`. 비우거나 다른 값이면 기본 가게(화분)로 그린다.

## 만들기

```sh
npm install
npm run dev        # 고치면서 보기
npm run build      # dist/ 에 올릴 파일이 생긴다
```

`?debug`를 붙이면 시간이 멈추고 `__step(초)`로 한 장씩 넘겨 볼 수 있다. `?tau=0.9`는 그 시각에 고정.
