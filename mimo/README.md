# MIMO 사이트 — 코드결 새 시안

이음이 만든 현재 사이트(mimo-ieum-preview)와 **별개로**, 같은 글과 작품으로 새로 지은 시안이다.
빌드 과정이 없다. 이 폴더를 그대로 웹 서버에 올리면 된다.

## 여는 법

```sh
cd mimo && python3 -m http.server 8765   # http://localhost:8765
```

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 글과 구조. 영문판은 이 글과 `app.js`의 `WORKS` 목록만 바꾸면 된다 |
| `style.css` | 색·글자·배치·움직임 |
| `app.js` | 카드 덱, 장면 전환, 영상 재생, 문의 내용 만들기 |
| `assets/` | 작품 영상 5편과 포스터, 미모 캐릭터 영상 4개, 디저트 영상. 현재 사이트에서 그대로 가져옴(재인코딩 없음) |
| `fonts/` | Pretendard(한글 2,350자 + 라틴만 남긴 판), Unbounded(라틴). 둘 다 SIL OFL |

## 화면별 주역 효과

1. 첫 화면 — 작품 카드 덱(밀어 넘기기, 가운데 카드만 재생, 작품 색으로 배경 빛 변화)
2. 띠 — 스크롤 속도에 따라 기울어지는 흐르는 글자
3. 작업물 — 작품마다 다른 장면 전환(위로 걷힘, 원형, 옆으로 걷힘, 사선, 회전)
4. 1인 스튜디오 — 스크롤하면 단어가 차례로 밝아지는 문단
5. 서비스 — 손가락·마우스를 따라오는 테두리 빛
6. 진행 순서 — 스크롤에 맞춰 채워지는 선
7. 맨 아래 — 글자 안에서 영상이 나오는 MIMO

## 지킨 것

- 영상은 한 번에 하나만 재생한다(덱 1개 또는 장면 1개).
- `prefers-reduced-motion`이면 움직임을 끄고 글·버튼·포스터만 보여 준다.
- 문의 양식은 내용을 정리·복사만 하고 전송하지 않는다.
- 가격 금액, 후기, 실적 표현은 넣지 않았다.
