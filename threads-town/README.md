# 스친 마을 (걸어 다니는 마을 샘플)

스친들의 가게가 모인 마을을 작은 손님이 걸어 다닌다. 빌드 과정과 외부 라이브러리가 없다. 이 폴더를 그대로 웹 서버에 올리면 된다.

```sh
cd threads-town && python3 -m http.server 8773   # http://localhost:8773
```

- 가고 싶은 집을 누르면 길을 따라 걸어가고, 문 앞에 서면 소개 카드가 열린다. 카드의 버튼은 그 사람의 스레드로 간다.
- 길 위 아무 곳이나 눌러도 걸어간다. 노트북에서는 방향키(또는 WASD)로도 움직인다.
- "마을 전체 보기"로 지도를 한눈에 보고, 거기서 집을 눌러도 된다.
- 들어올 때 닉네임과 옷 색을 고른다. 로그인은 없고, 이 기기에만 저장된다.
- 미모가 한가운데, 도원 쉼터(절)가 동쪽 마당에 있다. 빈 터에는 "입점 가능" 깃발이 꽂혀 있다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `residents.js` | 주민 목록(자리, 집 모양, 이름, 스레드 아이디, 소개). 주민이 바뀌면 여기만 고친다 |
| `houses.js` | 집과 꾸밈 그림. 집마다 함수 하나. 새 주민은 여기에 새 집을 그린다 |
| `town.js` | 지도(자리·길), 걷기, 화면 이동, 카드 |
| `index.html` | 화면 틀과 모양 |

## 주민을 더하거나 바꿀 때

`residents.js`만 고친다. 목록 순서대로 미모 집에서 가까운 자리부터 채워진다.

- 손으로 그린 집: `house`에 `houses.js`의 집 이름을 적는다 (먼저 입점한 10명과 미모, 도원 쉼터).
- 조립식 집: `house`를 비우고 `color`(지붕·문), `color2`(포인트), `roof`(gable·hip·flat·giwa), `props`(그림 최대 3개)를 적는다. 그림 이름은 `houses.js`의 `G` 목록에 있다.
- 지금 자리는 63개(가로 9 × 세로 7, 미모 집과 광장 칸 제외 61개 + 미모 + 쉼터). 60곳이 찼고 3곳이 "준비 중"이다.

## 마을을 더 키울 때

`town.js`의 `COLS`·`ROWS`를 늘리면 자리와 길이 같이 늘어난다. 화면 밖의 집은 그리지 않도록 되어 있다.

## 그림

참고한 외부 도구 없이 전부 새로 그렸다(SVG 색 면). 글꼴은 Pretendard(SIL OFL).

## 공개 전에

주민은 실제 스친의 스레드 프로필(이름·아이디·소개 글)을 바탕으로 했다. 소개는 줄여 쓴 것이라 본인 확인이 필요하고, 공개 전에 한 사람씩 동의를 받아야 한다. 프로필 사진은 쓰지 않았다.

## 함께 기능 (서로 보이기 · 손 흔들기 · 하트)

Firebase 무료(Spark) 요금제에 올렸을 때만 켜진다. 다른 곳에서는 자동으로 꺼지고 혼자 다니는 마을로 동작한다.

- `net.js` 서버 연결. `database.rules.json` 장난을 막는 규칙. `seed.json` 하트를 받을 수 있는 집 목록.
- 하트: 한 사람이 한 집에 20시간에 한 번. 10개에 꽃밭, 30개에 깃발, 100개에 반짝이는 별.
- 출석 일수와 닉네임·모습은 그 기기에만 저장된다.
- 주소 끝에 `?mock`을 붙이면 서버 없이 같은 브라우저의 창끼리 이어져서 시험할 수 있다.

### 올리는 순서 (처음 한 번)

1. Firebase 콘솔에서 프로젝트를 만들고, Realtime Database(잠금 모드)와 Authentication의 "익명" 로그인을 켠다. 웹 앱을 추가하면서 호스팅을 체크한다.
2. 이 폴더에서:

```sh
npm install -g firebase-tools
firebase login
firebase use --add            # 만든 프로젝트를 고른다
firebase database:set /houses houses.json  # 하트를 받을 수 있는 집 목록 넣기
firebase deploy               # 사이트와 규칙을 같이 올린다
```

`houses.json`은 집 열쇠 목록이고, `seed.json`은 같은 내용을 `{"houses": {...}}`로 감싼 것이다(콘솔의 "JSON 가져오기"용).

주민을 더하면 `residents.js`를 고치고, `/houses`에 그 사람 열쇠(아이디의 `.`을 `,`로 바꾼 것)를 `true`로 넣은 뒤 `firebase deploy`를 다시 한다.
