# 스레드 마을 (걸어 다니는 마을 샘플)

스친들의 가게가 모인 마을을 작은 손님이 걸어 다닌다. 빌드 과정과 외부 라이브러리가 없다. 이 폴더를 그대로 웹 서버에 올리면 된다.

```sh
cd threads-town && python3 -m http.server 8773   # http://localhost:8773
```

- 가고 싶은 집을 누르면 길을 따라 걸어가고, 문 앞에 서면 소개 카드가 열린다. 카드의 버튼은 그 사람의 스레드로 간다.
- 길 위 아무 곳이나 눌러도 걸어간다. 노트북에서는 방향키(또는 WASD)로도 움직인다.
- "마을 전체 보기"로 지도를 한눈에 보고, 거기서 집을 눌러도 된다.
- 들어올 때 닉네임과 옷 색을 고른다. 로그인은 없고, 이 기기에만 저장된다.
- 미모가 한가운데, 도원 쉼터(절)가 동쪽 마당에 있다. 빈 터에는 "입점 가능" 깃발이 꽂혀 있다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `residents.js` | 주민 목록(자리, 집 모양, 이름, 스레드 아이디, 소개). 주민이 바뀌면 여기만 고친다 |
| `houses.js` | 집과 꾸밈 그림. 집마다 함수 하나. 새 주민은 여기에 새 집을 그린다 |
| `town.js` | 지도(자리·길), 걷기, 화면 이동, 카드 |
| `index.html` | 화면 틀과 모양 |

## 마을을 키울 때

`town.js`의 `SLOTS`에 자리를 더하고 `ROADS`에 길을 더한다. 길 찾기는 길 목록에서 자동으로 만들어진다.

## 그림

참고한 외부 도구 없이 전부 새로 그렸다(SVG 색 면). 글꼴은 Pretendard(SIL OFL).

## 공개 전에

주민은 실제 스친의 스레드 프로필(이름·아이디·소개 글)을 바탕으로 했다. 소개는 줄여 쓴 것이라 본인 확인이 필요하고, 공개 전에 한 사람씩 동의를 받아야 한다. 프로필 사진은 쓰지 않았다.
