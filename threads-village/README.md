# 스레드 마을 (샘플)

펜으로 그린 마을. **가게 하나가 스친 한 명**이다. 가게를 누르면 자기소개가 나오고, 버튼을 누르면 그 사람의 스레드(또는 스토어·인스타 등 원하는 주소)로 간다.

- 거리 하나가 그림 한 줄이다. 거리가 꽉 차면 아래에 새 거리를 더한다.
- 빈 자리에는 "입점 가능" 팻말이 선다. 누르면 입점 안내가 나온다.
- 가게마다 주소가 있다. `1-3`은 1번가 3호. 먼저 들어온 가게일수록 앞 거리, 미모 가게 옆자리다.
- 해(밤에는 달)를 끌면 마을 전체 시간이 같이 바뀐다. 사람·고양이·참새도 눌러 볼 수 있다.
- 동작 줄이기 설정이면 저절로 움직이지 않는다.

## 주민을 더하거나 바꿀 때

`src/village.ts`만 고친다. 한 줄이 가게 하나다.

```ts
{ name: '가게 이름', handle: '@스레드아이디', intro: '자기소개 두세 줄', link: 'https://…', color: '#9a5b32', kind: 'bakery' }
```

- `kind`(가게 모양): `food` `fashion` `bakery` `books` `story` `cafe` `flower` `photo` `studio`. 비우면 기본 가게.
- `linkLabel`을 적으면 버튼 글자가 바뀐다(기본 "스레드 보러 가기").
- 빈 자리는 `{ vacant: true }`.
- **지금 들어 있는 주민은 모두 예시다.** 링크도 스레드 첫 화면으로 가는 임시 주소다.

## 만들기

```sh
npm install
npm run dev
npm run build      # dist/ 에 올릴 파일이 생긴다 (영상이 없어 가볍다)
```
